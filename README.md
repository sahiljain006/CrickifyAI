🧠 AI TECHNOLOGY & PROMPT ENGINEERING

AI is not just an additional feature in CRICKIFY AI. It is a core part of the platform's vision.

Google Gemini – Generative AI

The Google GenAI SDK enables communication with Google's Gemini models.

The AI Cricket Coach uses cricket-focused instructions and user queries to generate relevant conversational guidance.

Our prompt design approach:

1. Role-based prompting: Establish a cricket-coaching assistant persona.
2. Context engineering: Guide responses using cricket-specific context.
3. Intent understanding: Interpret the player's questions and learning needs.
4. Structured responses: Encourage clear, relevant, and understandable explanations.
5. Response refinement: Improve the quality and relevance of AI-generated guidance through prompt design.

MediaPipe – Computer Vision

MediaPipe Pose Landmarker provides the pose-detection capabilities used for movement analysis.

Processing workflow:

1. Receive supported visual input.
2. Detect body landmarks.
3. Extract pose and movement information.
4. Process available movement data.
5. Present relevant visual insights.

This creates a foundation for computer vision-assisted cricket technique learning.

🚀 Getting Started

Want to explore the project locally? Follow these steps.

Prerequisites

- Node.js installed
- npm package manager
- Git
- Google Gemini API key
- Firebase project configuration

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER

2. Install dependencies

npm install

3. Configure environment variables

Create a ".env.local" file in the project root.

Refer to ".env.example" for the exact variable names and configure the required credentials.

Typical configuration includes:

- Gemini API configuration.
- Firebase project configuration.
- Backend service configuration, if required.

Security: Never upload API keys, passwords, or private credentials to a public repository.

4. Start the development server

npm run dev

Open the local URL displayed in your terminal.

5. Build the application

npm run build

To preview the production build:

npm run preview

For projects with a separate backend package, follow its own installation and startup instructions.
